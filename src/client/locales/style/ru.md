# Russian (Русский)

- Use **ты**, like the game’s villagers. Speak to a group with вы: “Сравнивайте цены…”.
- Avoid past-tense verbs about the player, which would need a gender: write “цена покупки”, not “ты заплатил”; “Уже продано, но не записано?”, not “Продал и забыл записать?”. Players are **игрок** (“остров игрока {name}”), so names stay in the nominative and never need declining.
- Game terms, from the game’s Russian text: **репа**, **Дейзи-Мей**, **Лавка Нука** (“до закрытия Лавки Нука”), **Тимми** and **Томми**, **остров**. Never write турнипы, беллы, колокольчики or Дейзи Мэй.
- Bells are **дини**: 1 динь, 2 диня, 5 диней. Plural messages give all four forms (`one`, `few`, `many`, `other`). Elsewhere the number isn’t known, so put it where the genitive plural fits almost every number (“до {peak} диней”, “от {min} до {max} диней”), or, where the number changes as players watch, name the unit apart from it so every number reads right (“цена в динях — {price}”, “Цена продажи в динях выше {price}”). Prices like {price} or {best} arrive as bare numbers, so they fit anywhere, but phrases built on them, like “твои {price}” or “утренние {price}”, which other messages insert as {target} or {known}, must stay in the nominative or accusative: after a colon, in parentheses, after “чем”, or as the object of “превысит”.
- Turnips are counted the same way: 1 репа, 2 репы, 5 реп.
- Unsold turnips **гниют** (the game’s item is “гнилые репы”): “В воскресенье репа сгниет”, “Сгнившая репа”.
- Pattern names follow Turnip Prophet’s Russian translation, shortened where it’s long: **Колебания**, **Большой скачок**, **Снижение**, **Малый скачок**. A pattern is a **модель**. In sentences: “неделя снижения”, “неделя с большим скачком”, “указывают на <0>малый скачок</0>”; chips read “{chance} на снижение”.
- Half-days are labels, not phrases that decline: “понедельник, утро”, “понедельник, день”, in short labels and columns “Пн утро”, “Пн день”, and under the narrow chart columns “утр.”, “дн.”. In sentences they go in parentheses or after a colon: “Прогноз: {halfDay}”, “{price} ({halfDay})”. A half-day is a **период**; the weekday column is “День недели”, so it doesn’t clash with the afternoon column “день”.
- Times use the 24-hour clock: “в 8:00”, “до 22:00”, “до полудня”.
- Write е rather than ё, as the game does: “еще”, “сгниет”, “дает”.
- Use «» for quotations, an em dash with spaces ( — ) in sentences and an en dash without spaces in ranges (90–110).
