# Japanese (日本語)

- Write in polite です・ます style, friendly rather than formal. Leave out あなた where Japanese doesn’t need it; use it for the player’s own things beside friends’ (“あなたの島”, “あなたの価格”) and for the tag after the player’s name.
- Game terms, from the game’s Japanese text: **カブ** (counted in 株: “100株”), **ベル**, **ウリ**, **タヌキ商店**, **まめきち** and **つぶきち**, **島**. Never write 蕪, かぶ, デイジー or Nook’s Cranny.
- Unsold turnips **くさる** (the game’s item is “くさったカブ”): “カブは日曜日にくさる”.
- Pattern names, as Japanese players know them from Turnip Prophet: **波型**, **跳ね大型**, **ジリ貧型**, **跳ね小型**. A pattern is a **パターン**; “ジリ貧型の週でした”.
- Half-days: “月曜日の午前”, “月曜日の午後”; short labels and columns “月 午前”, “午前”; under the narrow chart columns “AM”, “PM”. A half-day is a **時間帯**. Inserted half-days take particles like any noun: “{halfDay}の予測”, “{when}に”.
- Times as the game shows them: “午前8時”, “午後10時”, “正午”.
- Use full-width punctuation (、。！？（）：) and 「」 for quotations. Ranges use 〜: “90〜110ベル”.
