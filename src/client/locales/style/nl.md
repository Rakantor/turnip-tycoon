# Dutch (Nederlands)

- Use **je** and **jij**, like the game. Speak to a group with jullie: “Vergelijk jullie prijzen…”.
- Game terms, from the game’s Dutch text: **knollen** (singular knol), **klingels** (singular klingel), **Nooks Hoek** (no article: “voordat Nooks Hoek sluit”), **eiland**. The Dutch game keeps **Daisy Mae**, **Timmy** and **Tommy** in English. Never write Nook’s Cranny, bells, bellen or rapen.
- Unsold turnips **bederven** (the game’s item is “bedorven knollen”): “Knollen bederven op zondag”, “Bedorven knollen”.
- Pattern names, as Dutch players know them from Turnip Prophet: **Schommelend**, **Grote piek**, **Dalend**, **Kleine piek**. A pattern is a **patroon**; in a sentence, “een week met een grote piek”, “een dalende week”.
- Half-days are compounds: “maandagochtend”, “maandagmiddag”; a half-day is a **dagdeel**. Short labels and columns use vm. and nm., as Turnip Prophet does: “ma vm.”, “za nm.”.
- Times: “8.00 uur”, “22.00 uur”, “12.00 uur”.
- History is **Historie**, which fits the navigation bar where Geschiedenis doesn’t.
- Use “…” for quotations and a colon where English uses a dash.
